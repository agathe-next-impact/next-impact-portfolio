# Nouveau client

## Avant de passer à « actif »

- [ ] Fiche organisation créée ou retrouvée (PILOTAGE → Veille personnalisée → Base des fiches organisation : raison sociale exacte, Pack de rattachement), puis reliée dans `Organisation`
- [ ] `Palier`, `Services`, `Début du contrat`
- [ ] Suivi technique : `ID projet WP Umbrella`
- [ ] Veille technique : `Site surveillé` et `Contact veille`
- [ ] Veille personnalisée : formulaire d'onboarding du pipeline soumis, puis `Veille — organisation` reliée
- [ ] Une ligne par personne dans **Personnes** (Nom, Email, Rôle, Client)
- [ ] Colonne « À compléter » vide

## Mise en service

- [ ] `État` → `actif`
- [ ] `/admin-cto/pilotage` → Synchro Notion : « À blanc », puis « Synchroniser »
- [ ] Fiche de l'accompagnement dans `/admin-cto` → « Envoyer l'invitation » pour chaque personne
- [ ] Premiers livrables publiés (`Publié`, `Affichage` = `À la une` pour l'accueil), prestations et leur échéancier dans **Paiements**
- [ ] « Prévenir les clients » : « À blanc », puis « Prévenir »
