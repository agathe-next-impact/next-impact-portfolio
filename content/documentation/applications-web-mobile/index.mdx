# Applications web & mobile

Cette catégorie regroupe les guides et ressources sur **les applications sur-mesure** — quand WordPress n'est plus le bon outil pour votre projet.

## Quand sortir du CMS ?

Trois familles de projets sortent du périmètre WordPress :

- **Web app sur-mesure** — marketplace, plateforme métier, outil interne, simulateur. Une logique métier propre, des comptes utilisateurs, des données temps réel.
- **Application mobile (PWA)** — outil terrain, jeu de piste, application installable sur smartphone sans passer par les stores.
- **Extension applicative** — un site Headless qui doit accueillir une zone applicative (espace membres, configurateur, e-learning).

## La promesse d'autonomie

Comme avec WordPress, vous gardez la main au quotidien. Chaque application livrée s'accompagne d'une **interface d'administration autonome**, conçue sur-mesure pour votre logique métier : vous gérez vos contenus, vos données et vos utilisateurs sans dépendance technique récurrente.
